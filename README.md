# Портфолио

Личный сайт начинающего веб-разработчика: **https://fuzzyrobotyt.github.io**

Сайт опубликован через GitHub Pages. Проекты учебные: они созданы в процессе обучения с помощью ИИ-ассистента (Claude). Код писался по шагам, я разбирал его, исправлял ошибки и проверял работу и безопасность.
